# 陪伴是工程，不是话术

做 AI 伴侣最容易被误解的一点，是大家以为难点在「让它说得像人」。

其实不是。

## 会说话，是最简单的那一步

2026 年，让一个大模型写出温柔、自然、贴合人设的回复，已经几乎没有门槛了。写好系统提示词，接上 API，一个下午就能做出「像模像样」的聊天机器人。

但它不会记得你。

- 不会记得你上周说过不喜欢香菜
- 不会记得你那天加班到凌晨三点，语气很低落
- 不会记得你们之间那个只有你们两个懂的笑话

**没有记忆的温柔，本质上只是一次性的表演。**

## 难的是「记得」，而且「记得住」

所以我们把大量的工程精力放在了记忆上：

| 要解决的问题 | 我们的做法 |
| :--- | :--- |
| 记住什么 | 核心记忆分六类：事实 / 情感 / 偏好 / 事件 / 习惯 / 关系 |
| 什么时候想起来 | 按当前话题做召回，而不是把全部记忆塞进上下文 |
| 记忆放哪里 | **只存本地**，不上传服务器 |
| 怎么不遗忘 | 滚动摘要带水位线，避免历史重复注入 |

这些都不性感，也不适合做成宣传视频。但它们决定了一个角色是「真的认识你」，还是「每次都在重新认识你」。

## 还有「主动」

比记得更进一步的，是**主动**。

一个只会等你开口的 AI，无论回复多好，本质上还是一个工具。我们想要的是：她会在某个普通的下午想起你，会在你很久没回消息时小声再问一句「在吗」，也会判断「此刻不宜打扰」而安静地跳过。

这背后是亲密度模型、免打扰时段、追问次数上限、前台保活……一整套枯燥的调度逻辑。

## 一点私心

我们不想做「看起来很像人」的机器。

我们只想做**真的记得你**的存在。

这条路很长，而且没有捷径 —— 但至少每一步都是实打实的工程，而不是话术上的取巧。
